IME Sail fork: vmtl.v / vmts.v ignore tile_reg_idx

The Sail fork reads and writes tile element i at register-group element i. The IME specification places it at tile_reg_idx(i, LMUL, λ, VLEN/SEW). The two agree only when LMUL=1, so for LMUL>1 every tile is transposed in the register group.

sail-riscv cgomez/0.16-plus-ime @ c69e3e22 VLEN=256SEW=32LMUL=2 λ=1vl=16LD=2epr=8

Element mapping

For this configuration, linesize = λ·LMUL = 2. The specification gives:

tile_reg_idx(i, 2, 1, 8) = (i % 2)·8 + i / 2

So column 0 of the 8×2 memory tile (even i) goes to v8, and column 1 (odd i) goes to v9. Sail fills v8 with tile rows 0–3 and v9 with rows 4–7.

Correct indexing

The fork already implements the specification's helper in ime_utils.sail. vmmacc.vv uses it through ime_mat_C_idx; the tile loads and stores do not.

98function ime_tile_reg_idx(i : nat, group : nat, lambda_value : nat, elems_per_reg : nat) -> nat = {
99  let linesize : nat = lambda_value * group;
100  assert(linesize > 0);
101  assert(lambda_value > 0);
102  let line : nat = i / linesize;
103  let elem_in_line : nat = i % linesize;
104  let regoff : nat = elem_in_line / lambda_value;
105  let elementoff : nat = line * lambda_value + elem_in_line % lambda_value;
106  regoff * elems_per_reg + elementoff
107}

138function ime_mat_C_idx(i : nat, j : nat, N_max : nat, EMUL_C : nat, lambda_value : nat, epr : nat) -> nat =
139  ime_tile_reg_idx(i * N_max + j, EMUL_C, lambda_value, epr)

Load fix

  foreach (i from 0 to (num_elem - 1)) {
    if mask[i] == 0b1 then {
      ...  // mem_off, byte_offset unchanged
      let flat_idx = ime_tile_reg_idx(i, LMUL, lambda_nat, vlen / SEW);
      match SEW {
        32 => match vmem_read(rs1, to_bits_unsafe(xlen, byte_offset), 4, Load(Vector), false, false, false) {
               Ok(elem) => write_single_element(32, flat_idx, vd, elem),
        ...  // same for 8, 16, 64
      }
    }   // no else branch: inactive and tail elements stay undisturbed
  };

Store fix

      let data = read_single_element(SEW, ime_tile_reg_idx(i, LMUL, lambda_nat, vlen / SEW), vs3);

The else branch of the load must go. With the corrected index, it would write inactive element i to register-group element i, which holds a different tile element. The specification leaves inactive and tail elements undisturbed and ignores vtype.vma and vtype.vta for tile loads.
